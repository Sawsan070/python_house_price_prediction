# Project 3: Python & Pandas Data Project

## 🎯 Wat heb ik gedaan?
Ik heb geleerd hoe ik met de programmeertaal Python naar data kan kijken. Met behulp van de populaire tool 'Pandas' heb ik van losse gegevens een mooie, nette tabel gemaakt (net als in Excel). Daarna heb ik de computer automatisch het gemiddelde van de huizenprijzen laten uitrekenen.

## 🛠️ Wat heb ik gebruikt?
* **Python 3**: De meest gebruikte taal voor data-analisten.
* **Pandas**: Het is eigenlijk de Excel van Python waarmee je data in nette tabellen zet en snel kunt doorrekenen.

## 🧠 Het Resultaat
De computer heeft de data ingeladen in een Pandas-tabel en direct berekend dat de gemiddelde huizenprijs **€ 350.000,-** is. 

## 🗂️ Wat zit er in dit mapje?
* `house_price_predictor.py`: Mijn Python-code waarin ik Pandas gebruik om de tabel te maken.
